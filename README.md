# 🎥 WatchLess AI – YouTube Video Summarizer

Skip the watch, get the knowledge.

WatchLess AI is an intelligent system that summarizes YouTube videos into concise, structured insights using advanced AI models. It extracts transcripts, processes content, and delivers key takeaways in seconds — saving time while maximizing learning.

---

## 🚀 Features

* 🔗 **YouTube URL Input** – Just paste a video link
* 🧠 **AI-Powered Summarization** – Converts long videos into short summaries
* 📝 **Transcript Extraction** – Fetches captions or generates transcripts
* ⏱️ **Key Highlights & Timestamps** – Quickly jump to important parts
* 📊 **Structured Output** – Bullet points, key insights, and summaries
* ⚡ **Fast & Efficient** – Designed for quick results

---

## 🛠️ Tech Stack

* **Frontend:** Streamlit / React (optional)
* **Backend:** Python
* **AI Models:** OpenAI / Hugging Face Transformers
* **Speech-to-Text:** Whisper / YouTube Transcript API
* **Libraries:**

  * `yt-dlp` / `pytube`
  * `transformers`
  * `langchain` (optional)
  * `streamlit`

---

## 🧩 How It Works

1. User inputs a YouTube video URL
2. System extracts transcript (captions or speech-to-text)
3. Text is cleaned and preprocessed
4. AI model generates:

   * Summary
   * Key points
   * Insights
5. Results are displayed in a structured format

